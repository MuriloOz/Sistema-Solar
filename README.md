🌌 Mini Sistema Solar

Este projeto é uma representação visual simplificada de uma parte do Sistema Solar, criada apenas com HTML e CSS.
O objetivo é demonstrar o movimento orbital da Terra em torno do Sol e da Lua em torno da Terra, utilizando animações puras em CSS.

🚀 Tecnologias Utilizadas

HTML5 – Estrutura da página

CSS3 – Estilização e animações

🌞 Descrição

O projeto simula de forma minimalista:

-- O Sol, posicionado ao centro com um efeito de brilho e gradiente dourado;

-- A Terra, orbitando o Sol com uma rotação contínua;

-- A Lua, girando ao redor da Terra com uma órbita mais rápida;

-- Todo o cenário é ambientado em um fundo preto, simulando o espaço sideral.

-- As animações são criadas com @keyframes e aplicadas às órbitas dos corpos celestes, proporcionando um movimento fluido e contínuo.

🖼️ Demonstração

Ao abrir o arquivo index.html no navegador, será exibida uma animação mostrando:

O Sol no centro;

A Terra girando ao seu redor;

A Lua orbitando a Terra.

💡 Conceito

A ideia central do projeto é explorar as possibilidades do CSS para criar animações visuais complexas sem o uso de JavaScript, representando um sistema orbital simplificado e educativo.
